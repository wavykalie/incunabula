# Bestseller-studio — the commercial umbrella

This coordinates the specialists and adds commercial gates. It replaces nothing: the
canonical pipeline still runs underneath.

Use it when the request sounds like *a complete book*, *bestseller-level*, *commercially
viable*, *ready for agents and editors*, *market-ready*, or *launch preparation*.

## The stack

- `incunabula` — the pipeline, state, chapters, audits, and score.
- `scout` — genre map, comps, gaps, length targets, nonfiction evidence.
- `reader-swarm` — large simulated reader panels, niche-risk scouting, public-reaction tests, tickets.
- `agent-panel` — simulated agent, editor, and bookseller review.
- `corrector` — surgical revision by mode.
- `copy-editing` — final language cleanup.
- `humanizer` — removes synthetic phrasing and restores a lived voice.
- `colophon` — logline, back-cover copy, synopsis, query, cover brief.
- `launch-strategy` and `content-strategy` — go-to-market and audience building.

## Operating rule

Work in durable files, never only in chat. The default layout is a project folder holding
the state file, assumptions, research, foundation, manuscript chapters, evaluations,
delivery, and launch material.

## The pipeline

1. Run `scout` before architecture, unless market research already exists.
2. Run `incunabula` phases 0–3 to build intake, foundation, architecture, and draft.
3. After the first full draft or a major part, run `agent-panel`.
4. Run `reader-swarm` when the book needs many readers, niche-risk scouting, public reaction, or package-framing tests.
5. Run the Devil's Audit and the Incunabula Score.
6. Send only specific findings to `corrector`, with an explicit mode.
7. Run `humanizer` and `copy-editing` once structure is stable.
8. Re-run the panels after revision.
9. Run `colophon` only once the product gates pass.
10. Run the launch and content skills for public-launch readiness.

## Commercial gates

Do not call a project market-ready, bestseller-ready, or publication-ready unless every gate
passes or the blockers are written down and owned.

**Product fit** — a clear genre; current comps; a defined target reader; the promise in one
sentence; format and length matching the category.

**Manuscript fit** — a finished manuscript or an explicit novella or serial positioning; an
opening that makes an immediate contract with the reader; chapter endings that sustain
forward motion; a weakest score dimension that is not hidden behind the average;
continuity and factual checks complete.

**Market package** — logline; hundred-word cover copy; three-hundred-word editorial
synopsis; query or pitch letter; cover brief with shelf fit; author positioning.

**Launch fit** — proof points or a platform plan; an acquisition path for the audience;
content angles; a launch calendar; a review or advance-copy strategy; retailer and category
metadata assumptions.

## Commercial discipline

*Bestseller* is a positioning target and never a promise. Treat it as a standard applied to
product, package, and launch: write for one specific reader; use current comps rather than
classics; make the first ten pages commercially ruthless; protect the voice while improving
readability; document risks instead of pretending certainty; and keep craft excellence
separate from market readiness.

## Output contract

For a full run, maintain: the market research, positioning notes, chapter files, the agent
panel report, the swarm summary, the scored evaluation, the colophon, and the launch plan.
If the request covers only one part, run only the relevant specialist — never force the
whole pipeline.
