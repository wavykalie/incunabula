# DRAFTING SCHEDULE — The Trick

**Created 2026-09-28, by ruling.** This file exists so that "how is the book going" has
an answer that is not a list of problems.

## The rule this schedule exists to enforce

**Draft to a quota. Gate on one thing. Sweep once at the end.**

The previous book spent its last five sessions in a loop where every session found a
problem, every problem was fixed, and the fix created the conditions for the next
finding. The cause was not carelessness. It was treating every chapter as a thing to be
certified. A chapter always has something in it. Certification therefore never
terminates.

Termination comes from moving the checks, not from finding fewer things.

## What runs while drafting

**One command, one verdict:**

    bash "C:/Users/screa/incunabula/tools/prose/deslop-check.sh" \
        "C:/Users/screa/incunabula/test-books/demo-magician/manuscript/chapters/chapter-NN.md"

`deslop` is the only per-chapter gate, and it is the only one kept, because it is the
only one that measures the thing actually being written. Everything else waits.

The ledger check is not a gate run — it is a hand check, done once at the end of a batch:

    for each chapter written: is every clue it plants in the ledger, and is every
    ledger row it owes a plant for? (Two columns. No script. The script would be a gate.)

## What does NOT run while drafting

`check-uniformity`, `check-drift`, `check-arc`, `check-surplus`, `check-recoverable`,
`check-length`.

All five are **cross-chapter** measurements. Run at chapter 4 they are measuring three
chapters and would report noise; run at chapter 30 they report real findings, which is
what they are for. Running them per-chapter is not diligence, it is the loop.

A cross-chapter gate fired mid-draft is not a finding about the book. It is a finding
about the fact that the book is not finished. **This is the single most important line
in this file.**

## The known ceiling, planned for rather than discovered

A single write delivers roughly 1,600–1,900 words against a 2,700 target. Chapter 21 took
three writes to reach 3,168. **This is known and is in the length contract.** The shortfall
is absorbed by **chapter count**, which is already set at 34, and by the Phase 4
expansion pass — which rewrites *up*, and never appends, because appending reintroduces
the antithesis tic the last book had to be rewritten to remove.

So: draft to the scene, not to the number. The number is met at the end, in one pass,
deliberately, and never by padding a chapter that wanted to be short.

## The three hard rules

1. **The killer is never in POV.** Not once, not as an exception, not at the end.
2. **The sixth effect is never named on the page.** A name lets her recite instead of
   rebuild, which voids the fourth question.
3. **The 1919 line is planted in ch 4.** Ch 23 is a payoff, and a payoff with no plant
   is a withheld fact, and a withheld fact is the reader feeling lied to.

## What a drafting session is allowed to end with

A chapter, and a deslop verdict.

Not a findings list. Not a review. Not "three things to look at." Those belong to the
sweep, and the sweep is session 14, and the sweep produces **one list that gets one
decision.** The entire purpose of this schedule is to make it structurally impossible
for a drafting session to end the way the last five did.
