# Voice Bank: Kagiroi Drift

This repository holds gold-standard reference prose samples for *Kagiroi Drift*. The Writer must read these before drafting any chapter.

## Standards
1. **Sensory Immediacy**: Every paragraph must have concrete physical friction.
2. **Tactile Chemistry**: Intimacy is raw, sensual, and grounded in zero-g bodily physics.
3. **Voice Under Pressure**: Characters drop cadence and syntax when stressed.
4. **Anti-AI Cleanliness**: Zero overprint antitheses, minimal em-dashes, no boilerplate tropes.
